# Project Declaration

## Project Name

**Multitasker**

## Description

Multitasker is a task management web application built with Laravel and Livewire. Registered users will be able to create an account, log in, create and manage multiple task lists, and add, edit, update, delete, and organize tasks. Each task belongs to a single list and includes a due date and priority level. Users will only be able to access and manage their own lists and tasks.

## Project Structure

- Laravel
- Livewire
- Authentication (registration and login)
- SQLite database with migrations
- CRUD operations for Lists and Tasks
- Responsive UI using Livewire and FluxUI components
